Buffer Circular O(1) vs. Array com Deslocamento O(n)
Desconectado
Vertente 1 (Ineficiente): A cada inserção num buffer cheio, todos os N elementos são deslocados à esquerda — complexidade O(n). A latência por operação cresce linearmente com N.

Vertente 2 (Ring Buffer): Apenas os índices Head e Tail são incrementados — complexidade O(1). A latência permanece constante independente de N. O modelo Produtor-Consumidor permite que o loop de sensores continue sem bloqueio durante o envio MQTT.
